# Report on the Mini Meetup – First Cloud AI Journey

## 1. Mini Meetup Objectives

The Mini Meetup – First Cloud AI Journey was a knowledge-sharing event organized by the FCAJ community for participants interested in Cloud Computing, Artificial Intelligence, and modern technologies.

The event provided an opportunity to gain foundational knowledge of cloud computing, explore different hosting models and server options, and understand the importance of building a professional profile in the technology industry.

The main objectives of the meetup were:

- To explore fundamental concepts and learning pathways in Cloud Computing.
- To understand different hosting models and server infrastructure options.
- To learn how to develop a professional profile through LinkedIn.
- To exchange knowledge and experiences with people interested in Cloud and technology.

## 2. Speakers and Topics

The meetup included three main presentations:

- **Phung Hai Long – Marketing Manager, Thanh Cong Group:** LinkedIn and Personal Branding.
- **Phuong Nguyen:** The Very First Step into the Cloud.
- **Pham Minh Quang:** Right Server, Right Job – Comparing Hosting Types and Server Options.

## 3. Key Topics

### 3.1. LinkedIn and Personal Branding

The first presentation focused on the importance of LinkedIn in developing a professional image and expanding career opportunities. Besides technical knowledge, students need to present their skills, experience, and career objectives clearly.

Key takeaways included:

- Building a professional LinkedIn profile that reflects personal interests and career goals.
- Presenting technical knowledge, skills, and completed projects to demonstrate practical capabilities.
- Connecting with technology communities and industry professionals.
- Sharing learning experiences and project achievements to gradually develop professional credibility.

This session helped me recognize the importance of documenting my learning process and presenting practical projects as part of my professional development.

### 3.2. The Very First Step into the Cloud

The second presentation introduced the fundamental concepts of Cloud Computing and provided an overview of the initial steps toward learning cloud technologies.

The key learning points included:

- Understanding Cloud Computing and the benefits of using computing resources over the Internet.
- Becoming familiar with cloud services and the ability to provision and scale resources.
- Recognizing the importance of foundational knowledge in networking, servers, storage, and security.
- Combining theoretical learning with hands-on practice on cloud platforms.

The presentation helped me understand that a solid foundation in cloud infrastructure is essential before implementing solutions on AWS. This knowledge is particularly relevant to my internship project, which involves deploying an application and implementing backup and disaster recovery mechanisms.

### 3.3. Right Server, Right Job – Comparing Hosting Types and Server Options

The third presentation discussed different hosting models and server options. It emphasized that infrastructure should be selected according to the actual requirements of each application.

Key topics included:

- Exploring common hosting models and server infrastructure options.
- Comparing performance, scalability, management capabilities, security, and operating costs.
- Selecting server resources based on application requirements.
- Balancing technical needs with available budgets when designing infrastructure.

These insights helped me understand the importance of choosing suitable AWS resources for the Maiora website, particularly the application server running on Amazon EC2 and the database hosted on Amazon RDS.

## 4. Knowledge and Skills Gained

### 4.1. Technical Knowledge

- **Cloud Computing:** Improved my understanding of cloud computing concepts and the benefits of cloud-based infrastructure.
- **Server Infrastructure:** Gained a clearer understanding of selecting hosting models and server configurations according to application requirements.
- **Networking Fundamentals:** Recognized the importance of networking knowledge when configuring connectivity between cloud resources.
- **Security and Cost Optimization:** Understood the need to consider security, performance, and operating costs when designing cloud systems.
- **Cloud Resource Management:** Became more familiar with the importance of managing and using cloud resources efficiently.

### 4.2. Personal Development Skills

- Learned how to build a professional profile and present technical capabilities through LinkedIn.
- Recognized the importance of documenting practical work and completed projects.
- Developed a stronger motivation for independent learning and continuous technology development.
- Improved my awareness of knowledge sharing and professional networking.

## 5. Application to My Internship Project

My internship project is titled **"Research and Implementation of a Backup and Disaster Recovery System on Amazon Web Services (AWS)."**

The project uses Maiora, a fashion e-commerce website, as a practical application to demonstrate the deployment of cloud infrastructure, data backup, and system recovery.

The knowledge gained from the meetup can be applied to the project in the following ways:

- **Infrastructure Selection:** Apply knowledge of server options to select appropriate AWS resources, including Amazon EC2 for the application server and Amazon RDS for the MySQL database.
- **Cloud Infrastructure Design:** Apply foundational cloud knowledge when designing the AWS environment, including networking, storage, and security configurations.
- **Backup and Disaster Recovery:** Develop an understanding of the importance of protecting application data and preparing recovery solutions to maintain service availability.
- **Cost Optimization:** Select suitable resource configurations and manage cloud resources carefully to avoid unnecessary expenses.
- **Professional Portfolio Development:** Document the implementation process, technical challenges, backup and restoration tests, and project results for future academic and career development.

## 6. Event Experience

Participating in the Mini Meetup – First Cloud AI Journey on August 15, 2026, provided me with useful perspectives on cloud technologies, server infrastructure, and professional development.

The presentation about Cloud Computing helped me strengthen my understanding of cloud fundamentals and encouraged me to continue exploring AWS services. The discussion about hosting models and server options also helped me recognize that infrastructure decisions should be based on application requirements, performance expectations, security, and cost.

In addition, the LinkedIn and Personal Branding session highlighted the importance of presenting technical knowledge and practical achievements clearly. I realized that documenting my internship project, including the deployment of the Maiora website and the implementation of backup and disaster recovery solutions, would be valuable for building my professional profile.

## 7. Conclusion and Lessons Learned

Through the Mini Meetup – First Cloud AI Journey, I gained additional knowledge about Cloud Computing, server infrastructure options, and personal branding in the technology industry.

The most important lesson was that successful cloud implementation requires both foundational technical knowledge and careful infrastructure planning. Resource selection should consider application requirements, security, performance, and budget constraints.

These insights provided useful preparation for my internship project on AWS Backup and Disaster Recovery, especially when deploying the Maiora application, configuring cloud resources, and developing a suitable backup and recovery strategy.
