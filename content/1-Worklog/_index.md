# Internship Worklog

### Overview

This section presents the worklog of my internship, which was completed over a period of 10 weeks, from August 10, 2026, to October 18, 2026.

During this period, I researched, designed, and implemented a Backup and Disaster Recovery (DR) system on Amazon Web Services (AWS). The project used Maiora, a fashion e-commerce website, as a practical application to demonstrate cloud infrastructure deployment, data backup, and system recovery.

The work was organized into weekly activities, starting with an introduction to AWS and its fundamental services, followed by the deployment of the web application, database configuration, storage setup, backup implementation, and disaster recovery testing.

The main activities completed during the internship are summarized below:

### Weekly Activities

**Week 1:** [Introduction to AWS and Basic Cloud Services](1.1-week1/)

Learned about the internship program, working rules, AWS Management Console, AWS CLI, and fundamental AWS services.

**Week 2:** [AWS Networking and EC2 Infrastructure](1.2-week2/)

Studied Amazon VPC, CIDR, public and private subnets, route tables, Internet Gateway, Security Groups, Network ACLs, and Amazon EC2.

**Week 3:** [Linux Environment and Web Application Deployment](1.3-week3/)

Prepared the Amazon Linux environment, installed and configured Apache and PHP, and developed the initial version of the Maiora fashion e-commerce website.

**Week 4:** [Amazon RDS and MySQL Database Configuration](1.4-week4/)

Configured Amazon RDS for MySQL, created the application database, and established connectivity between the EC2 application server and the database.

**Week 5:** [Amazon S3 Storage and Cross-Region Replication](1.5-week5/)

Stored product images in Amazon S3, enabled S3 Versioning, and configured Cross-Region Replication (CRR) to protect image data across AWS Regions.

**Week 6:** [AWS Backup Configuration and Backup Management](1.6-week6/)

Created an AWS Backup vault and backup plan, configured resources for backup, and examined backup jobs and recovery points.

**Week 7:** [Primary and Disaster Recovery Environment Setup](1.7-week7/)

Studied and prepared the primary environment in Singapore and the Disaster Recovery environment in Sydney to support cross-Region recovery.

**Week 8:** [Backup Restoration and Data Integrity Verification](1.8-week8/)

Performed restoration from backup recovery points and checked the availability and integrity of recovered application and database resources.

**Week 9:** [Disaster Recovery Scenarios and RTO/RPO Evaluation](1.9-week9/)

Simulated application server and data failure scenarios, examined the recovery process, and evaluated system performance using Recovery Time Objective (RTO) and Recovery Point Objective (RPO).

**Week 10:** [System Testing and Internship Report Completion](1.10-week10/)

Reviewed the system configuration, completed backup and disaster recovery testing, collected AWS evidence screenshots, summarized test results, and finalized the internship report.
