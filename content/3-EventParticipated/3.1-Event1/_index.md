## 1. Event Objectives

The Mini Meetup – First Cloud AI Journey, held on August 15, 2026, was a knowledge-sharing event organized by the FCAJ community. The event provided participants with opportunities to explore topics related to personal branding, cloud computing, and server infrastructure.

The main objectives of the event included:

- Understanding the importance of personal branding and professional networking in the technology industry.
- Gaining an overview of cloud computing and its practical applications.
- Learning about different hosting types and server options.
- Understanding how to select appropriate server infrastructure based on application requirements.
- Encouraging continuous learning, knowledge sharing, and professional development within the technology community.

## 3. Key Topics

### 3.1. LinkedIn and Personal Branding

The first session focused on the importance of building a professional image and developing a personal brand through LinkedIn. In the technology industry, professional networking and personal branding can help individuals connect with experts, discover career opportunities, and share their knowledge and experience.

Key takeaways included:

- Understanding the role of LinkedIn in professional networking.
- Learning how to build a clear and professional personal profile.
- Recognizing the importance of sharing knowledge and professional achievements.
- Developing communication and networking skills.
- Maintaining a professional image when interacting within the technology community.

### 3.2. The Very First Step into the Cloud

The second session introduced the fundamental concepts of cloud computing and its role in modern information technology systems.

Cloud computing allows users to access computing resources such as servers, storage, databases, and networking services over the Internet without having to manage all physical infrastructure themselves.

Some important topics included:

- Understanding the concept and basic characteristics of cloud computing.
- Learning about the benefits of using cloud services, including flexibility, scalability, and resource optimization.
- Becoming familiar with cloud service models such as IaaS, PaaS, and SaaS.
- Understanding how cloud platforms support application deployment and infrastructure management.
- Exploring the practical applications of cloud computing in businesses and technology projects.

This session provided a foundation for understanding how cloud platforms can be used to deploy, manage, and maintain modern applications.

### 3.3. Right Server, Right Job – Comparing Hosting Types and Server Options

The third session focused on different hosting models and server options, emphasizing the importance of selecting infrastructure that matches the requirements of an application.

Different applications may require different levels of computing resources, availability, security, and scalability. Therefore, choosing an appropriate hosting solution is an important part of system design.

Key aspects included:

- Understanding common hosting types and their characteristics.
- Comparing the advantages and limitations of different server solutions.
- Considering CPU, memory, storage, and network requirements when selecting a server.
- Evaluating scalability and flexibility when deploying applications.
- Understanding the relationship between infrastructure costs and system performance.

The session highlighted that selecting the right server is not simply about choosing the most powerful option, but about matching resources to actual application requirements.

## 5. Application to the Internship Project

My internship project is **"Research and Development of a Backup and Disaster Recovery System on Amazon Web Services (AWS)"**. The project focuses on building a fashion e-commerce website named Maiora on AWS and implementing backup and disaster recovery solutions to protect application data and support service recovery when incidents occur.

The knowledge gained from the Mini Meetup can be applied to the project in several ways:

- **Cloud Infrastructure Selection:** The session about cloud computing provided foundational knowledge for understanding AWS infrastructure and selecting suitable services for the Maiora website.
- **Server Selection and Configuration:** Knowledge about hosting types and server options helped me better understand the selection of Amazon EC2 instances based on application requirements and available resources.
- **Database and Storage Infrastructure:** The project uses Amazon RDS to store application data and Amazon S3 to store product images. Understanding cloud infrastructure helps clarify the role of different services in the overall system architecture.
- **Backup and Disaster Recovery:** Selecting appropriate infrastructure is important when designing backup and recovery solutions. The project uses AWS Backup to protect EC2 and RDS resources, while Amazon S3 Versioning and Cross-Region Replication support product image protection across AWS Regions.
- **Cost Optimization:** The session emphasized the importance of matching infrastructure resources to actual needs. This is relevant to the project because cloud service costs must be controlled during deployment, backup operations, and recovery testing.
- **Regional Infrastructure:** The project uses Singapore as the primary AWS Region and Sydney as the recovery region. Understanding cloud infrastructure helps clarify how resources can be organized across different regions to support disaster recovery.

These topics provided useful foundational knowledge for understanding cloud infrastructure and making appropriate technical decisions during the implementation of the Backup and Disaster Recovery system.
